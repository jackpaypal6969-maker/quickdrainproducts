# Quick Drain Products — build conventions (read before writing any file)

Stack: FastAPI 0.x + Jinja2 (autoescape ON, `trim_blocks`, `lstrip_blocks`) + SQLite + Stripe hosted Checkout + Tailwind v4 (static build, class names only) + vanilla JS in `static/js/app.js`. No React, no Alpine, no inline `<script>` that executes (CSP `script-src 'self'`), no Google Fonts, no emoji as icons.

## Rendering
- Routes call `render(request, "path/template.html", ctx, conn=conn)` from `app/deps.py`. Every template automatically receives: `request`, `path`, `csrf_token`, `canonical`, `cart_count`, `customer` (dict or None), `site` (settings table dict), `promo_banner`, `flash` ({message, kind}) plus globals `settings` (app/config.py Settings), `render_jsonld()`, `asset()`, `current_year()`.
- Page templates `{% extends "base.html" %}` and fill `{% block content %}`. Optional context keys read by base.html: `meta_title`, `meta_description`, `og_image`, `og_type`, `jsonld` (list of dicts), `no_index`, `hide_newsletter`.
- Admin templates extend `admin/base.html` (to be written in templates/admin/base.html) which itself must extend nothing; it is a standalone dark layout with a left nav. Admin routes pass `admin` (dict), `counts` (nav badge counts: orders_open, orders_hold, reviews_pending, rma_open, contact_new, low_stock), `section`, `meta_title`.
- Email templates live in `templates/emails/<name>.html` (+ optional `.txt`). They receive `settings`, `base_url`, `unsubscribe_url`, `category` plus per-template context (see app/services/*.py callers). Emails must be table-based, inline-styled, dark palette optional but must be readable in light clients; always include the unsubscribe link for `category == 'marketing'` and a plain footer with the phone number.

## Filters and macros
Filters: `est_date`, `est_datetime`, `est_time`, `est_short` (America/New_York), `fmt_money` (cents → `$12.99`), `fmt_money_short`, `plural(n, "item")`, `md` (safe markdown-lite → HTML; the ONLY way HTML from content reaches a page).
Macros: `{% from "components/icons.html" import icon, stars %}` → `icon('cart', 20, 'class')`, `stars(4)`. `{% from "components/picture.html" import picture %}`. `{% from "components/faq.html" import faq %}`. `{% from "components/dose_ledger.html" import ledger %}`.
Never use `|safe` on user content. Review text, names, addresses, notes: plain `{{ }}` only.

## CSS vocabulary (static/css/src/app.css — use these, do not invent new component classes)
Layout: `container-x`, `section`, `section-tight`. Type: `eyebrow`, `lede`, `h1`, `h2`, `h3`, `prose`, `display`. Buttons: `btn` + `btn-primary|btn-secondary|btn-ghost|btn-danger`, sizes `btn-sm|btn-lg`, `btn-block`. Surfaces: `card`, `card-pad`, `panel`, `hairline`, `glow-top`, `glow-bottom`. Forms: `label`, `input` (also on select/textarea), `help`, `field`, `checkbox`, `choice` + `choice-body`. Feedback: `alert alert-ok|alert-error|alert-warn`, `badge badge-accent|badge-danger|badge-success|badge-warning`, `skeleton`. Tables: `table`, `table-wrap`, `num`. Nav: `nav-link`, `icon-btn`, `link`. Tailwind colour utilities available: `bg-bg bg-bg-alt bg-bg-deep bg-surface bg-surface-2 bg-raised bg-accent bg-accent-soft`, `text-ink text-muted text-nav text-faint text-accent text-accent-tint text-on-accent text-danger text-success text-warning`, `border-line border-line-soft border-line-strong`, fonts `font-display font-body font-mono`, radii `rounded-md rounded-lg rounded-pill`. Everything else is standard Tailwind v4.
Motion: add `data-reveal` on blocks that should fade+rise in; `data-reveal-stagger` on a parent whose direct `data-reveal` children stagger 60ms. Nothing else animates.

## Forms and security
Every state-changing `<form method="post">` includes `<input type="hidden" name="csrf_token" value="{{ csrf_token }}">`. Public forms include the honeypot `<input type="text" name="website" tabindex="-1" autocomplete="off" class="hidden" aria-hidden="true">` where the route checks `website`. Inputs are ≥44px tall (`input` class does this). Labels are visible (`label` class), never placeholder-only. Every icon-only button has `aria-label`.

## Voice
Plain, specific, no hype. The product is a maintainer: one bottle = one drain-month (label: "dosed for monthly use on any drain", 4 fl oz / 118 mL, "natural drain enzyme"). Never claim what the label does not (no septic-safe claim, no "dissolves X", no percentages). When the drain is backing up, the answer is a diagnostic visit at quickdrainny.com / (631) 888-6200, not a bottle.
